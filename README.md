# Автобраузер для Android

Приложение-браузер с ИИ. Вы открываете сайт и говорите (голосом 🎤 или текстом), что сделать:
«нажми Войти», «введи в поиск котики и нажми Enter», «выбери город Москва».
ИИ (Claude, через API) смотрит на страницу и сам нажимает нужное. **Каждое действие записывается в сценарий.**
Потом сценарий запускается **без ИИ** — быстро, бесплатно и одинаково каждый раз.

## Установка

1. Откройте на телефоне [Releases → latest-build](../../releases/tag/latest-build) и скачайте `autobrsr.apk`.
2. Разрешите установку из этого источника и установите.
3. В приложении: **⚙ Настройки** → вставьте ключ API Anthropic (`sk-ant-...`).
   Ключ нужен только для записи с ИИ; запуск готовых сценариев работает без него.

APK собирается автоматически GitHub Actions при каждом пуше (`.github/workflows/android.yml`).

## Как пользоваться

**Запись.** «＋ Новый» → название и адрес сайта → «Начать запись». Сверху браузер, снизу чат:

```
🗣 нажми на «Войти» вверху
   ✔ 1. нажать кнопка «Войти»
🤖 Открыл форму входа.
🗣 введи логин ivan и пароль, сделай их переменными
   ✔ 2. ввести поле логина = "{{login}}"
   ✔ 3. ввести поле пароля = "{{password}}"
```

- Можно нажимать по странице и самому — эти действия тоже записываются (✋). Отключается в настройках.
- **Шаги** — список записанного, **↶ Отменить** — убрать последний шаг, **▶ Проверить** — прогнать сценарий без ИИ.
- Сценарий сохраняется автоматически при выходе.

**Запуск без ИИ.** Нажмите на сценарий → «▶ Запустить». Если есть переменные — приложение спросит значения
(по умолчанию — те, что были при записи).

**Ещё:** «Дописать с ИИ» (воспроизводит сценарий и продолжает запись), «Поделиться JSON» / «Импорт».

## Как это устроено

| Файл | Что делает |
|---|---|
| `assets/autobrsr.js` | встраивается в страницу: снимок элементов для ИИ, селекторы, действия, запись ручных нажатий |
| `WebDriver.kt` | управление WebView из фонового потока: JS, нативные касания, клавиши, скриншоты, ожидание загрузки |
| `StepRunner.kt` | выполнение шагов и воспроизведение сценария без ИИ |
| `Agent.kt` | цикл Claude с инструментами (`click`, `type_text`, `select_option`, …); каждое действие → шаг |
| `ClaudeClient.kt` | запросы к Messages API (без сторонних библиотек) |
| `RecordActivity` / `RunActivity` / `MainActivity` | экраны записи, запуска и список сценариев |

**Почему сценарий не ломается от мелких изменений сайта.** Для каждого элемента записывается несколько способов
его найти — `data-testid` → `id` → `name` → роль+текст (`кнопка «Войти»`) → подпись поля → placeholder → текст → CSS-путь.
Сохраняются только те, что при записи находят ровно этот элемент. При запуске они пробуются по очереди.

Нажатия выполняются нативными касаниями по WebView (как пальцем), поэтому работают и на сайтах, которые
игнорируют «программные» клики.

## Формат сценария

```json
{
  "name": "вход",
  "startUrl": "https://example.com",
  "variables": { "login": "ivan" },
  "steps": [
    { "action": "click", "target": { "description": "кнопка «Войти»",
        "strategies": [{ "type": "role", "role": "button", "name": "Войти" }, { "type": "css", "value": "body > header > button" }] } },
    { "action": "type", "value": "{{login}}", "submit": true, "target": { "description": "поле логина",
        "strategies": [{ "type": "css", "value": "input[name=\"login\"]" }] } }
  ]
}
```

Действия: `navigate`, `back`, `click`, `hover`, `type` (`submit`, `clear`), `select`, `check`, `press`, `scroll`,
`wait`, `wait_for_text`, `extract` (`save_as`).

## Сборка вручную

```bash
./gradlew assembleRelease   # нужен Android SDK (ANDROID_HOME)
```

## Ограничения

- Элементы внутри `iframe` пока не видны.
- Капчи и SMS-коды — вручную.
- Ключ API и значения переменных (в т.ч. пароли) хранятся в памяти приложения открытым текстом.
- Модель по умолчанию — `claude-opus-5-5`, меняется в настройках. Каждая команда ИИ — платный запрос к API.

# Autobrsr — ИИ-автобраузер с записью сценариев

Идея: вы обычным языком говорите ИИ, что сделать в браузере («открой сайт, введи логин, нажми Войти»),
он сам находит нужные элементы и кликает. Каждое действие **записывается в сценарий**.
Потом сценарий можно запускать **без ИИ** — быстро, бесплатно и одинаково каждый раз.

```
 ┌──────────── запись (с ИИ) ────────────┐        ┌──── запуск (без ИИ) ────┐
 вы: «нажми Войти»                                  scenarios/login.json
   → Claude видит страницу (элементы+скриншот)        → Playwright выполняет шаги
   → вызывает click(element_id=7)                     → ищет элементы по записанным
   → Playwright кликает                                 селекторам (с запасными)
   → шаг + устойчивые селекторы → сценарий           → подставляет переменные
```

## Установка

```bash
npm install
npx playwright install chromium   # если браузер ещё не установлен
export ANTHROPIC_API_KEY=sk-ant-...
```

## Запись сценария

```bash
node src/cli.js record login --url example.com
```

Дальше просто пишите команды:

```
вы> нажми на кнопку «Войти» в правом верхнем углу
   ✔ click «кнопка Войти»
🤖 Открыл форму входа.
вы> введи логин ivan и пароль 12345, логин и пароль сделай переменными
   ✔ type «поле логина»
   ✔ type «поле пароля»
🤖 Ввёл логин и пароль.
вы> нажми продолжить
вы> /save
```

Служебные команды: `/steps` — показать шаги, `/undo` — убрать последний шаг, `/go <url>` — открыть адрес,
`/var имя=значение`, `/replay` — проверить запись без ИИ в новой вкладке, `/save`, `/quit` (сохраняет автоматически).

`--continue` — воспроизвести существующий сценарий и дописать его новыми командами.

## Запуск без ИИ

```bash
node src/cli.js run login                                 # с окном браузера
node src/cli.js run login --headless --var login=petr --var password=secret
node src/cli.js list
node src/cli.js show login
```

Если шаг не выполнился — код выхода 1 и скриншот `failed-step-N.png`. Удобно для cron/CI.

## Формат сценария

Обычный JSON в `scenarios/`, его можно править руками:

```json
{
  "name": "login",
  "startUrl": "https://example.com",
  "variables": { "login": "ivan" },
  "steps": [
    {
      "action": "type",
      "value": "{{login}}",
      "target": {
        "description": "поле логина",
        "strategies": [
          { "type": "css", "value": "input[name=\"login\"]" },
          { "type": "label", "value": "Логин" },
          { "type": "css", "value": "body > form > input" }
        ]
      }
    },
    { "action": "click", "target": { "description": "кнопка Войти",
      "strategies": [{ "type": "role", "role": "button", "name": "Войти" }] } }
  ]
}
```

Действия: `navigate`, `click`, `hover`, `type` (`submit`, `clear`), `select`, `check`, `press`, `scroll`,
`wait`, `wait_for_text`, `extract` (`save_as`), `screenshot` (`path`, `full_page`).

### Почему сценарий не ломается от мелких изменений сайта

При записи для каждого элемента собирается несколько способов его найти — от надёжных к хрупким:
`data-testid` → `id` → `name` → роль+текст (`button "Войти"`) → подпись поля → placeholder → текст → CSS-путь.
Сохраняются только те, что на момент записи находят **ровно этот** элемент. При запуске пробуются по порядку,
пока один не сработает.

## Настройки

| Переменная | По умолчанию | |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ API (нужен только для записи) |
| `AUTOBRSR_MODEL` | `claude-opus-5-5` | модель |
| `AUTOBRSR_EFFORT` | `medium` | `low` быстрее/дешевле, `high` — для сложных страниц |
| `AUTOBRSR_MAX_ACTIONS` | `25` | лимит действий на одну команду |
| `AUTOBRSR_SCENARIOS` | `./scenarios` | папка сценариев |

`--no-vision` при записи — не отправлять скриншоты (дешевле, но ИИ видит только список элементов).

## Устройство

- `src/browser.js` — запуск Chromium, снимок страницы для ИИ, построение и поиск селекторов, выполнение шагов
- `src/agent.js` — цикл Claude с инструментами (click, type_text, select_option, …); каждое действие → шаг сценария
- `src/player.js` — воспроизведение без ИИ
- `src/scenario.js` — сохранение/загрузка JSON
- `src/cli.js` — команды `record`, `run`, `list`, `show`

Тесты (без ключа API, с поддельным сервером): `npm test`.

## Ограничения и идеи

- Элементы внутри `iframe` пока не видны агенту.
- Капчи и двухфакторка — вручную.
- Идея на будущее: режим «самолечения» — если при запуске без ИИ элемент не найден, один раз спросить ИИ по `description` шага и обновить селекторы.
